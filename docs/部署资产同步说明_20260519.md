# 宠物管理系统升级后部署资产同步说明（2026-05-19）

本文档说明今天系统升级后，除了通过 GitHub 同步代码以外，还需要单独传输哪些模型、图片、数据库结构和演示数据。按本文档放置后，前端、Spring Boot 后端和 Python FastAPI 模型服务可以在其他设备上复现当前功能。

## 1. 本次升级涉及的模块

本项目实际包含三个子仓库：

| 子目录 | 作用 | 是否通过 Git 同步 |
| --- | --- | --- |
| `pet/` | Vue 前端 | 是 |
| `backEnd/` | Spring Boot 后端 | 是 |
| `ai_recognition/` | Python FastAPI 统一 AI 服务 | 是 |

但以下内容通常不适合直接放进 Git，必须单独传输：

- AI 模型权重与 ONNX 文件
- Demo 宠物图片、测试图片
- 数据库表结构增量 SQL
- 如果要直接复现演示数据，还需要数据库数据备份或重新执行种子脚本

### 5.2 方案 B：在目标设备重新生成 demo 数据

适合目标设备也有 PetFace 数据集，并且 Python AI 服务可以正常运行。

前置条件：

- PetFace 数据集已解压，例如：

```text
/Volumes/ORGOS - Data/PetFaceWorkspace/ai_petface/data/PetFace
```

- Python AI 服务已启动：

```bash
cd ai_recognition
export KMP_DUPLICATE_LIB_OK=TRUE
PET_BREED_MODEL_DIR=models_extended python inference_server.py
```

- 确认健康检查：

```bash
curl http://localhost:8000/health
```

- 安装 `pymysql`：

```bash
conda activate pet
python -m pip install pymysql
```

生成 60 条 demo：

```bash
cd /path/to/pets
conda run -n pet python backEnd/scripts/seed_petface_demo.py \
  --petface-root "/Volumes/ORGOS - Data/PetFaceWorkspace/ai_petface/data/PetFace" \
  --animals dog cat \
  --limit 60 \
  --profile-images-per-pet 3 \
  --query-candidates-per-pet 6 \
  --min-query-score 0.60 \
  --ai-url http://localhost:8000 \
  --mysql-host 127.0.0.1 \
  --mysql-port 3306 \
  --mysql-user root \
  --mysql-password 123456 \
  --mysql-db petSql \
  --clear-demo
```

说明：

- `--clear-demo` 只清理 `chip_number LIKE 'DEMO-PETFACE-%'` 的演示宠物和对应演示用户，不会删除普通用户真实创建的宠物。
- 脚本会生成每只宠物 3 张建档图和 1 张 recommended 测试图。
- 低于 `--min-query-score` 的候选个体会跳过，脚本继续寻找下一只补足数量。

## 10. 注意事项

- 不要把 `PetFace` 原始数据集上传到 GitHub。它有学术使用限制，且体积很大。
- 运行系统不需要完整 PetFace 数据集，只需要模型文件和数据库中的 embedding。
- 运行系统也不需要 `dataset_extended/`，除非要重新训练 1.1 品种模型。
- `backEnd/uploads/images/` 中 demo 图片文件名不要改，否则数据库中的图片 URL 会失效。
- 如果换了后端端口或域名，数据库中的 demo 图片 URL 当前仍是 `http://localhost:8080/upload/images/...`。本地演示没问题；若部署到远程服务器，可以考虑后续改成相对路径或统一文件域名。
- 如果 `PetFace` 模型启动时首次加载 backbone，可能需要访问 Hugging Face 下载 `BVRA/MegaDescriptor-B-224` 的基础模型缓存。若目标设备离线，需要提前准备 Hugging Face 缓存或保证首次启动时联网。
